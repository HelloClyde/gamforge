# 9288T 2.5 MiB EXE 上限实验（2026-10-16）

下文记录的是取消压缩之前的历史实验。后续内嵌模式已改为未压缩 `.data`
零副本资源，不再调用 `malloc(C6502_GAME_SIZE)` 或解压；启动快照也改为原字节。
历史 EXE 大小、哈希、堆分配失败结论仅对应当时的构建，不代表新构建的体积。
文件窗口与真实可用内存的验证边界仍然适用，见 [资源布局](architecture.md#未压缩资源与内存归属)。

## 实现边界

9288T 的限制改为完整 KF2 文件不超过 **2,621,440 字节**。这不是 malloc
上限，也不是扩大模拟器或真机内存。其它目标保持完整 EXE 小于 1 MiB。
CLI、打包器、链接器共用目标配置；链接边界计入 `.bss` / `.noinit`。
当前容器开销 536 字节，因此最大 payload 的地址范围为
`[0x02700000, 0x0297FDE8)`，不是完整 2.5 MiB payload。

## 完整固件模拟器测试

复用现有 Dream9288T Preview 隔离实例（8771），没有新增模拟器进程或
调整 RAM 配置。其既有启动参数为 `--ram-size 0x00100000`、
`--sdram-size 0x02000000`，后者为 32 MiB。通过模拟器的事务式 FAT 上传
接口安装到已有应用入口，经固件桌面启动，不是直接注入 ELF 后跳转 PC。
上传后下载核验文件完全相同。

### 精确边界探针：通过

`9288T-2.5MiB-PROBE.exe` 恰好 2,621,440 字节；它不是空白填充后只运行前端代码：

- 在 `0x02710000` 起放置按地址变化的测试数据，逐字检查 2,555,304 字节。
- 在 `0x0297FDA8` 放置可执行函数，实际调用并核对返回值。
- 核对载入区域最后一字节为 `0xA5`。
- 保持 GUI Timer / 系统服务正常运行，写出 `A:\A25M.LOG` 并自动返回桌面。

两轮边界数据检查均通过。最终探针 SHA256：
`2b534bf69c7beab15b89e292f6f4b94262bfe988d89399d4fff9a31def491797`。

### 文件大小和运行内存仍是不同限制

同一探针通过 SDK 实际分配并释放，得到：

```text
malloc_1966080_address=0
malloc_1048576_address=39040784
```

即本次固件环境下 1,966,080 字节连续申请失败，1,048,576 字节申请成功。
这不是对可用堆上限的完整二分测量，不能据此写死一个新的 malloc 最大值。

《仙剑四》单 EXE 成功编译为 1,535,157 字节（含内嵌压缩资源），但在完整
固件启动后回到桌面，没有进入游戏。其单文件资源路径会先调用
`malloc(C6502_GAME_SIZE)`，本游戏为 1,966,080 字节；该申请失败时当前代码
直接返回。上述独立分配结果与此现象一致，但没有把这份游戏标为通过。
仅放宽文件上限并不能解决其整份资源解压的连续内存需求，仍须外置资源
或另行调整资源驻留策略。

## 回归与验证范围

实际游戏对照：启用性能统计和按需崩溃追踪（启动时追踪关闭）的《伏魔记》
单 EXE 为 **1,063,977 字节**，超过旧 1 MiB 15,401 字节。完整固件实际进入
开场动画、“新的征程 / 再续前缘”菜单和“天地玄黄”开场文字。其游戏资源为 851,968 字节，
因此没有触发上述《仙剑四》的 1,966,080 字节连续申请问题。
SHA256 为 `579cdde9f0b76b943fbaccf666492e72ba7513fcf15e231a0882c5203277dbcf`。
这只是超限后启动/菜单冒烟测试，不是全流程游戏回归或真机速度测试。

实际仓库运行以下测试 **118 passed**：`test_executable_limits.py`、
`test_compiler.py`、`test_resources.py`、`test_targets.py`、`test_converter.py`。
包含真实 S1C33 链接器的默认/9288/9288T 精确边界与超出一字节检查，
并验证超限不会覆盖已有输出。取消进程测试在具备本地子进程权限后也通过。

固件反汇编中 CRTL `ansi_InitMalloc` 初始化的堆区为
`[0x02500000, 0x02700000)`，没有与向上扩展的应用映像直接重叠。
但这只排除该堆的冲突：模拟器 32 MiB SDRAM 不等于真机容量证据，也没有
证明所有固件版本的栈、音频、DMA 或其它缓冲都不会占用高地址。
本改动仍标为**实验性、未真机验证**。没有推送或发布新版本。

原始日志、探针源码、构建脚本、地图文件及截图保留于本地
`bbk9288-gam4988/build/t-25m/`；不把游戏内容提交到翻译器仓库。
