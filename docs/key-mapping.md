# 转换时自定义按键映射

按键映射是编译配置，不修改 GAM，也不会在运行时打开或读取配置文件。
修改后需要重新转换 EXE；已经生成的 EXE 保持原来的映射。

## 支持范围

| 输出机型 | 自定义映射 | 输入入口 |
| --- | --- | --- |
| 9288 | 支持 | 原有键盘矩阵采集 |
| 9288T | 支持 | 原有系统 GUI 按键消息 |
| 9288S | 不支持 | 固定软键盘 |
| 听说王600 | 不支持 | 固定软键盘 |

图形界面选择 9288 或 9288T 后，点击「按键映射…」，为实体键选择对应的
A 系列按键，点击「应用」。每种机型独立保存设置，也可以「恢复默认」。
9288S 和听说王600 隐藏此入口；命令行显式传入映射会报错，不会静默忽略。

可以修改功能键、字母键和数字键，支持多个实体键映射到同一个游戏功能，
也可以禁用某个键的游戏输入。电源、方向、确定、退出和实体 Shift 键保持固定，
不能作为自定义映射来源；其他键可额外映射到这些游戏动作（系统电源除外）。
游戏是否响应该动作取决于游戏自身。

9288T 默认：开始→查找，翻译→插入，朗文→修改，考场→删除。
9288 保留原先的映射以避免改变既有游戏操作：其中实体帮助键原先对应
4980 插入，实体删除键原先对应 4980 帮助，实体开始对应 4980 开关键。
这些历史对应关系会明确显示在配置窗口中，现可自行调整。

调试版仍保留原有追踪快捷键：9288 的实体 D、9288T 的实体 Shift+D；
启用崩溃追踪时该组合优先于游戏映射。普通非追踪版没有此占用。

## 命令行

先查看目标机型的实体键标识与可选游戏按键：

```text
GAMForge-CLI.exe convert --target 9288t --list-key-maps
```

使用可重复的 `--key-map HOST=GUEST` 参数，例如把 T 的开始键改成帮助，
考场键改成空格，其余使用默认值：

```text
GAMForge-CLI.exe convert game.gam --target 9288t --key-map start=help --key-map exam=space --output game.exe
```

9288 的示例：开始→查找，帮助→帮助，删除→删除：

```text
GAMForge-CLI.exe convert game.gam --target 9288 --key-map start=search --key-map help=help --key-map delete=delete --output game.exe
```

其他标识包括 `letter_a`、`digit_1`、`page_up`、`page_down`、`input`、
`catalog`、`speech`。目标值 `none` 表示不向游戏送出该键。
不接受任意数值扫描码、未知名称或同一来源的重复配置。

`.report.json` 中记录完整 `key_mapping`、自定义差异 `key_mapping_overrides`
和 `key_mapping_supported`。GUI 保存的是各机型差异，不会污染其他机型默认值。

## 实现约束

- 9288 来源编码为矩阵 `row * 8 + column`；9288T 为官方 GUI 扫描码。
  不能根据 SDK 中旧的功能键别名跨机型猜测位置。
- 9288T 四个实体功能键使用 `MSG_HOTKEY` 按下和普通 `KEYUP` 松开，
  与普通/SYS/DT 消息共享 held 状态，避免同一次按下重复入队。
- 映射在捕获输入时执行一次，队列内保存最终游戏按键。互换映射不会递归转换。
- 自定义设置生成数字常量 C 表，纳入构建配置与追踪 build ID。
  零自定义项时编译掉查表分支；不增加磁盘 I/O。
- 系统电源、宿主默认消息分派、启动/退出输入屏障保持原路径；
  触屏机型不会应用此表。
