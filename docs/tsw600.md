# 听说王600 输出（实验性）

机型 ID 为 `tsw600`，GUI 名称为“听说王600”。这是独立的安装目标，
不是把 9288S EXE 改名；它复用 S 的最小平台运行载荷，不修改 GAM 翻译语义。

## 格式依据

本地听说王600 系统 dump 中的原机“扫雷”等 EXE 使用 D300 + EXE 双头。
现有 BBASIC 的 S / 600 对照构建同样只修改以下两个主头字段：

| 字段 | 9288S | 听说王600 |
| --- | --- | --- |
| 0x0C，8 字节 GBK 分类 | 娱乐 | 游戏 |
| 0x50，32 位小端兼容标记 | 0x12345678 | 0x0000D500 |

LICON 位于 0x100，含 16 字节描述及两帧 32×32 2-bpp 图像，程序位于 0x310。
同样的游戏、标题、图标、资源方式和编译设置下，生成的 S / 600 EXE 应在归一化
上述字段后逐字节一致。官方 Apmk 对照检查也必须比较完整文件，而不是只检查魔数。
原机 EXE 和 kernel dump 仅用于本地检查，不纳入源码或翻译器分发包。

## 共享平台边界

当前共用 9288S `Down_Include`、GNU33 ABI、S1C33 工具链、平台窗口代码与运行库；
不要选择 9288T `include` 或 9588 SDK。不重复打包一套相同的头文件。
听说王600 的手册确认了触摸屏及方向、确定、开关/退出键；这不是所有固件私有
API 或硬件寄存器均兼容的证明。

共享显示布局为 160×240、2-bpp：上半屏游戏 159×96，偏移 (0,12)，最右隐藏位遮白；
下半屏为数字、QWERTY、空格、翻页、方向、ENTER / ESC 软键。
保持 S 的物理六键读取、SDK 校准触摸坐标、私有 edge/repeat FIFO、256 Hz CTM 游戏时钟和
退出恢复规则。详细实现见 [9288S 适配](9288s.md)。

## 使用

GUI 选“听说王600”，或运行：

```powershell
GAMForge-CLI.exe convert "游戏.gam" --target tsw600 --app-name "游戏"
```

v1.3.0 全套包自动使用包内 `dependencies/sdk9288s`；源码用 `--sdk` 或 `ATSW600_SDK` 指定。
未设置 600 环境变量时允许使用 `A9288S_SDK`，但 GUI 会分别记忆 S / 600 的手动配置。
EXE 安装到 `A:\系统\程序\`，从“游戏”分类启动。
外置模式的配套 RES 安装到 `A:\系统\数据\`；不要改名或混用。

## 验证与限制

已覆盖原机包头对照、完整 Apmk 封装、S / 600 载荷归一化对照、中文 GUI 目标映射、
SDK 头文件选择、私有 FIFO、四目标自检、即时 framebuffer 全像素和构建回归。
私有游戏仅作本地转换检查，不随翻译器分发。

**未进行听说王600 真机启动、触控、存档和性能验证。**
S 模拟器启动证据只能证明共享载荷在 S 上的部分行为，不能称为 600 模拟器验证。
包头正确、构建成功或图标可见均不证明游戏全流程兼容；不同固件版本仍可能需要平台修正。
